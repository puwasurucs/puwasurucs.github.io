Privacy policy

Statement automation is a private tool used only by its owner, signed in to the owner's own Google account. No one else's data is accessed.

What it accesses

  • Gmail: it searches the owner's mailbox for emails from a fixed list of statement senders, reads the attachments of those emails, and adds one label to each email it has filed. It does not send, delete or move email, and it does not change whether an email is read or in the inbox.
  • Google Drive: it checks whether a statement is already in the owner's statement folders and, if not, uploads the unlocked PDF there.

How the data is used and stored

Data is used only to file the owner's statements into the owner's own Google Drive. Each run processes the attachments in memory on a short-lived build machine and keeps nothing once the run ends: no copies, no databases, no analytics. Statements are stored only in the owner's own Gmail and Google Drive.

Sharing

No data is sold, shared or transferred to anyone, used for advertising, or used to train AI or machine-learning models.

Statement automation's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/connections.
